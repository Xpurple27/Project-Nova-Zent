# NOVA ZENITH — MVP sprite contract
Art direction: ART_BIBLE.md. Runtime source of truth: src/game/animation/manifest.ts. Original SVG placeholder sheets are generated by scripts/generate-placeholder-art.mjs and dedicated CC0; no external copyrighted assets are used. Regenerate with node scripts/generate-placeholder-art.mjs.

| Mode | Frame | Columns | Origin | World scale | Direction convention |
|---|---|---|---|---|---|
| Exploration | 96×128 | 4 | (0.5,1), feet | 0.5 (64px tall) | rows idleS/walkS/idleW/walkW/idleE/walkE/idleN/walkN |
| Character combat | 128×160 | 4 | (0.5,1) | CSS 0.5 | face enemy (right); display layer may mirror |

Every sheet is transparent, without trimming/rotation. Each clip occupies one full row; column indexes 0–3. Frames share the same foot point and silhouette scale. Leave 8px safety margin. Neutral portrait/master reference exports should be separate 512×512 transparent images; these are production art deliverables, not required for runtime placeholders.

Warrior: idle/slash/shield/provoke/hurt/ko/lastBastion/recovery. Mage: idle/arcaneCast/overchargeCast/frostCast/hurt/ko/meteorCast/recovery. Thief: idle/quickStrike/focus/exposeWeakness/dodge/hurt/ko/execution/recovery. Healer: idle/holyCast/healingWave/blessing/ward/hurt/ko/divineRecovery/recovery. Guardian: idle/entrance/claw/spear/wave/roar/armor/barrier/charge/cataclysm/hurt/phase/death.

Names and paths live in the manifest; replace source files there to use PNG/WebP sheets without changing combat logic. Four frames per clip is the frozen MVP export contract. Idle/walk loop; normal one-shots 600ms, KO/death 800ms, major attacks 1800ms maximum. Controller consumes monotonically sequenced semantic events; frame indexes never reach gameplay UI. HP snapshots keep KO persistent. Revive briefly recovers then returns idle. Impact frames cannot apply gameplay mutations.

Phaser lazily loads exploration sheets only. React combat uses CSS sprite sheets. Failed sheet loading uses the procedural/map or semantic glyph fallback; gameplay remains usable. Reduced-motion mode uses a static semantic frame, no shake. Remove listeners/tweens on scene shutdown; CSS timers/images are canceled on React cleanup. Keep decoded exploration textures under 8MiB for four characters; avoid unrelated cinematic/4K image bundles.

Production review: approximately 5.5-head non-chibi silhouette, consistent 3/4 camera and dramatic lighting; Warrior blue steel + sword/shield; Mage violet + staff; Thief shadow + dual blade; Healer gold/white + staff; Abyss dark stone/crimson. Placeholders deliberately communicate class role rather than claim finished character artwork.
