# NOVA ZENITH — MVP sprite contract
Art direction: ART_BIBLE.md. Runtime source of truth: src/game/animation/manifest.ts. Original SVG identity proxy sheets are generated by scripts/generate-placeholder-art.mjs and dedicated CC0; no external copyrighted assets are used. Regenerate hero/Guardian proxies with node scripts/generate-placeholder-art.mjs. Existing normal-enemy sheets are maintained separately.

Every sheet is transparent, without trimming/rotation. Each clip occupies one full row; column indexes 0–3. Frames share the same foot point and silhouette scale. Leave 8px safety margin. Illustrated full-body WebP exports are 512×768 for heroes; Guardian is 768×702. Portrait derivatives are 256×256, cropped from each same master. Paths and epithets are centralized in game/animation/identity.ts. Never use the artwork rectangle as collision.

Warrior: idle/slash/shield/provoke/hurt/ko/lastBastion/recovery. Mage: idle/arcaneCast/overchargeCast/frostCast/hurt/ko/meteorCast/recovery. Thief: idle/quickStrike/focus/exposeWeakness/dodge/hurt/ko/execution/recovery. Healer: idle/holyCast/healingWave/blessing/ward/hurt/ko/divineRecovery/recovery. Guardian: idle/entrance/claw/spear/wave/roar/armor/barrier/charge/cataclysm/hurt/phase/death.

Names and paths live in the manifest; replace source files there to use PNG/WebP sheets without changing combat logic. Four frames per clip is the frozen MVP export contract. Idle/walk loop; normal one-shots 600ms, KO/death 800ms, major attacks 1800ms maximum. Controller consumes monotonically sequenced semantic events; frame indexes never reach gameplay UI. HP snapshots keep KO persistent. Revive briefly recovers then returns idle. Impact frames cannot apply gameplay mutations.

Phaser lazily loads exploration sheets only. React combat uses CSS sprite sheets. Failed sheet loading uses the procedural humanoid/map fallback; illustrated character cards fall back to the matching real sprite, then retain readable class labels; gameplay remains usable. Reduced-motion mode uses a static semantic frame, no shake. Remove listeners/tweens on scene shutdown; CSS timers/images are canceled on React cleanup. Keep decoded exploration textures under 8MiB for four characters; avoid unrelated cinematic/4K image bundles.

Production review: approximately 5.5-head non-chibi silhouette, consistent 3/4 camera and dramatic lighting; Warrior blue steel + sword/shield; Mage violet + staff; Thief shadow + dual blade; Healer gold/white + staff; Abyss dark stone/crimson. Illustrated character identity is implemented. World motion remains a four-frame SVG proxy; React combat uses the same standing artwork with semantic cast/hurt/KO/recovery transforms. These are not fully painted frame-by-frame attacks. The proxy and illustration palettes/equipment must stay aligned.
