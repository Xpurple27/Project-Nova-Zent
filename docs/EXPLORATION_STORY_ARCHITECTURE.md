# Exploration/story/encounter authority — campaign V1

React owns the authoritative snapshot and input/UI. One dynamically imported Phaser 3.90 renderer owns the disposable map/camera/sprites; its port contains only view, local axis, ephemeral remote packets and intent/cue callbacks. Combat remains React + the original shared server engine. No Phaser HP or progression calculator exists.

Persistent campaign fields in the existing CAS document: version, scene, sceneToken, completed encounter IDs, rally votes, active roster, current encounter, completed story IDs, current story instance/start/end/logical step/skip votes. PostgreSQL root row lock/CAS, command receipts, turn UUIDs and event sequence protect the entire run, including world transitions. No new coordinate table is created. The private relational turn/action/question/event audit is retained; final turn metadata survives return to exploration.

Flow: START locks roster and enables campaign for newly started rooms → opening → Village → Forest Path → Hound → Ruins Path → Shaman → Ancient Ruins → Boss Chamber → entrance → existing Guardian combat → ending → COMPLETED (persisted outcome VICTORY). Existing persisted boss-only documents are not rewritten. Encounter HP reset/resource40/Ultimate≤50 follow the frozen blueprint. Enemy scaling remains locked to the initial roster, including disconnects. Turn/event sequence and question history continue across encounters.

## Movement
Private topics: nz:motion:{roomUUID}:{authUserUUID}. SELECT requires receiver and sender to be non-LEFT room members; INSERT additionally binds sender to auth.uid. Each member subscribes to the frozen party's ≤4 per-sender topics. Payload identity is never trusted to select an actor. Motion DTO: scene/token, stream UUID, monotonic seq, x/y, direction, idle/walk, timestamp. Coordinates must be finite and within the scene; stale scene tokens/streams/sequence are ignored. This is cosmetic client-authoritative movement, not spatial anti-cheat.

Emit ≤10Hz while moving, immediate state-change updates within that cap, 1Hz idle heartbeat. Remote tracks interpolate 120ms behind arrival time, keep ≤8 frames, and hide after 5s without packets. Render frames never write PostgreSQL. Reconnect/refresh resets to a per-seat safe checkpoint, not an unreliable stored pixel coordinate. A failed initial room identity lookup retries every 3s; subscriptions/timers/game instance are removed on scene/route teardown. Durable sceneToken changes clear the local interaction prompt and reconstruct the renderer once.

## Party transitions
Only the configured current gate can request rally. All active nondeparted frozen-roster members within the existing 60s heartbeat grace must agree. The UI obtains the request from a nearby exit; the server enforces ordered gates and party agreement, rather than pretending untrusted coordinates prove proximity. No client chooses an arbitrary destination or marks an enemy complete. A disconnected member expires from the required set after grace. A completely abandoned world suspends its pending agreement and aborts after 10min, avoiding permanent watchdog writes.

## Story
Definitions live in game/story; cutscene/contract re-exports the typed semantic command model. Opening48s, encounter hooks4s, entrance12s, ending14s. Server absolute timestamps and skip votes drive logical completion; no client ACK can stall it. All active grace-roster members must vote skip. Both timeout and skip apply the same server final state/encounter dispatch exactly once. Reconnect seeks current logical time and existing camera/actor state without replaying historical one-shot sounds. Phaser's command executor handles camera/actor/fade/animation/VFX/audio presentation; it cannot mutate canonical progression. Dialogue is React and supports keyboard/touch/reduced motion.

## Recovery and limits
Any missed Realtime hint is repaired by the existing 3s snapshot poll and heartbeat/reconnect path. Lower versions are ignored; latest durable snapshot wins. Motion packet loss may affect cosmetics briefly, never HP/results/encounter completion. Normal enemy and boss resolution share one engine and input/deadline/reaction pipeline. UI scene-load errors are nonfatal and provide reload guidance. Lost anonymous credentials still cannot be reconstructed across devices. Final art, spatial anti-cheat, map streaming, exact pixel persistence and Stage2 remain excluded.
